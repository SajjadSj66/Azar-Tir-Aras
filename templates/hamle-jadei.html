{% if LANGUAGE_CODE == 'fa' %}زمان تقریبی حمل بار از مبدا تا مقصد چقدر است؟{% else %}What is the approximate shipping time from origin to destination?{% endif %} ＋

{% if LANGUAGE_CODE == 'fa' %} زمان حمل جاده‌ای بسته به مسافت و شرایط جاده معمولاً بین ۱ تا ۵ روز کاری متغیر است. مسیرهای طولانی مانند تهران به بندرعباس حدود ۲ تا ۳ روز زمان می‌برد. {% else %} Road transport time usually varies between 1 to 5 working days depending on distance and road conditions. {% if LANGUAGE_CODE == 'fa' %}حداقل و حداکثر وزن قابل حمل در حمل جاده‌ای چقدر است؟{% else %}What is the minimum and maximum weight for road freight?{% endif %} ＋

{% if LANGUAGE_CODE == 'fa' %} از خرده‌بار با وانت (از ۵۰۰ کیلوگرم) تا محموله‌های سنگین با تریلی کمرشکن (تا ۲۵ تن) قابل حمل است. نوع ناوگان بر اساس وزن بار انتخاب می‌شود. {% else %} From small parcels with a pickup (from 500 kg) to heavy shipments with a low-bed trailer (up to 25 tons) can be carried. The fleet type is selected based on cargo weight. {% endif %}

{% if LANGUAGE_CODE == 'fa' %}چه نوع ناوگانی برای حمل جاده‌ای در دسترس است؟{% else %}What types of fleet are available for road freight?{% endif %} ＋

{% if LANGUAGE_CODE == 'fa' %} وانت، خاور، کامیون تک، کامیون جفت، تریلی کفی، تریلی چادری، تریلی یخچال‌دار و کمرشکن از جمله ناوگان موجود برای حمل جاده‌ای هستند. {% else %} Pickup, light truck, single-axle truck, tandem truck, flatbed trailer, curtain-side trailer, refrigerated trailer and low-bed trailer are among the fleets available for road freight. {% endif %}

{% if LANGUAGE_CODE == 'fa' %}مدارک لازم برای حمل جاده‌ای چیست؟{% else %}What documents are required for road freight?{% endif %} ＋

{% if LANGUAGE_CODE == 'fa' %} بارنامه، فاکتور فروش، کارت ملی راننده و گیرنده بار از مدارک اصلی هستند. برای برخی کالاها مانند مواد غذایی، مجوز بهداشتی نیز لازم است. {% else %} Waybill, sales invoice, national ID of driver and consignee are the main documents. For some goods such as food items, health permits are also required. {% endif %}

{% if LANGUAGE_CODE == 'fa' %}هزینه حمل جاده‌ای چگونه محاسبه می‌شود؟{% else %}How is the road freight cost calculated?{% endif %} ＋

{% if LANGUAGE_CODE == 'fa' %} هزینه بر اساس وزن بار، مسافت، نوع ناوگان و عوارض جاده‌ای محاسبه می‌شود. در آذر تیر ارس تعرفه‌ها شفاف و بدون هزینه پنهان است. {% else %} Cost is calculated based on cargo weight, distance, fleet type and road tolls. At Azar Tir Aras, tariffs are transparent with no hidden costs. {% endif %}

{% if LANGUAGE_CODE == 'fa' %} بله، تمام ناوگان آذر تیر ارس مجهز به GPS هستند و شما می‌توانید موقعیت دقیق بار خود را به صورت لحظه‌ای پیگیری کنید. {% else %} Yes, all Azar Tir Aras fleets are equipped with GPS and you can track the exact location of your cargo in real-time. {% endif %}

{% if LANGUAGE_CODE == 'fa' %}شرایط بسته‌بندی برای حمل جاده‌ای چگونه باید باشد؟{% else %}What are the packaging requirements for road freight?{% endif %} ＋

{% if LANGUAGE_CODE == 'fa' %} بسته‌بندی باید در برابر ضربه، لرزش و شرایط جوی مقاوم باشد. برای کالاهای حساس، استفاده از پالت و ضربه‌گیر توصیه می‌شود. {% else %} Packaging must be resistant to impact, vibration and weather conditions. For sensitive goods, using pallets and shock absorbers is recommended. {% endif %}

{% if LANGUAGE_CODE == 'fa' %}تفاوت حمل جاده‌ای با سایر روش‌ها چیست؟{% else %}What is the difference between road freight and other methods?{% endif %} ＋

{% if LANGUAGE_CODE == 'fa' %} حمل جاده‌ای انعطاف‌پذیری بالایی دارد و امکان تحویل درب به درب را فراهم می‌کند. نسبت به حمل هوایی ارزان‌تر و نسبت به حمل ریلی سریع‌تر است. {% else %} Road freight is highly flexible and offers door-to-door delivery. It is cheaper than air freight and faster than rail freight. {% endif %}

{% if LANGUAGE_CODE == 'fa' %}آیا حمل جاده‌ای برای کالاهای خاص مناسب است؟{% else %}Is road freight suitable for special goods?{% endif %} ＋

{% if LANGUAGE_CODE == 'fa' %} بله، برای کالاهای فاسدشدنی از تریلی یخچال‌دار، برای ماشین‌آلات سنگین از کمرشکن و برای کالاهای حجیم از تریلی کفی استفاده می‌شود. {% else %} Yes, for perishable goods refrigerated trailers are used, for heavy machinery low-bed trailers, and for bulky goods flatbed trailers. {% endif %}
